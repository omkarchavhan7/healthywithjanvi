Healthy Bites with Janvi — responsive landing page

Open index.html in your browser, or open the folder in VS Code.
Files: index.html, style.css, script.js, assets/.

The hero section uses the supplied Healthy Bites hero design, cropped below its
embedded navigation so the site's real responsive navigation remains usable.
The hero image itself includes its headline, paragraph, and buttons as part of
the supplied artwork.

Search and cart are demo interactions only. Real orders, checkout, payment, inventory,
WhatsApp notifications, and saved customer details require a backend or service integration.
